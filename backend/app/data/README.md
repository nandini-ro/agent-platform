# Bundled data

`countries.json` is a trimmed extract of the
[mledoze/countries](https://github.com/mledoze/countries) dataset, used by the
`travel_info` tool. It is made available under the
[Open Database License (ODbL) v1.0](https://opendatacommons.org/licenses/odbl/1-0/);
the extract keeps only the fields that tool reads (names and codes, capital,
region, currencies, languages, calling codes, borders, flag).
